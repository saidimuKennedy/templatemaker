# ADR-004: Mobile-First Webviews

## Status

Accepted

## Decision

The builder is optimized first for mobile webviews, especially WhatsApp.

## Rationale

This aligns with the primary product use case and encourages performant,
responsive designs.

## Alternatives

-   Desktop-first
-   General website-first

## Consequences

Components, layouts, and previews prioritize small screens while
remaining reusable elsewhere.
